# Tovali

Website for Tovali, an all-day cafe — croissants and chai in the morning, ramen and pasta at night.

Live: https://tovali.vercel.app

## What's in it

- Preloader, scroll-driven sections and a horizontal "day at the cafe" timeline (GSAP + ScrollTrigger, Lenis smooth scroll)
- Menu with category tabs and tilt cards (Framer Motion)
- Table booking with a live SVG floor plan: pick a day, time and party size, then tap a free table
- Respects `prefers-reduced-motion`

## Stack

React 18 · Vite · Tailwind CSS · GSAP · Framer Motion · Lenis

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build`; the output goes to `dist/`.
